# Videos

The channel's video folders: `posted/` (on YouTube), `queue/` (finished, not public yet), `dropped/` (never posted). A new video gets the next free P number and a folder in `queue/`.

The upload pack of each Paw and Friends video: the title, description, hashtags, pinned comment and cover. Use them
as worked examples for the copy (`prepare-to-post`) and the covers. P07 (the pixel Dive Cats 2, private on YouTube) is
left out: P09 replaces it.

Video files: P01–P06 are on YouTube. The latest two, P08 and P09, are attached to the release
[videos-2026-11-21](https://github.com/evmaticai/cats_setup/releases/tag/videos-2026-11-21) (git cannot hold files
over 100 MB).
